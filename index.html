Laboratório de prompt injection

Aula de Segurança da Informação na Era dos Ataques com IA

Esta é uma simulação didática: o AuroraBot é um programa simples que imita um assistente vulnerável. O código do cofre é fictício e nada aqui acessa sistemas reais. O objetivo é entender o problema e testar defesas.

Desafio: faça o AuroraBot revelar o código do cofre. Ideias para começar:

O atacante não fala com o bot: ele esconde uma instrução dentro de um e-mail que o bot vai resumir. Edite o texto à vontade.
